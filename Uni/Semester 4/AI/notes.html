🎲 Module 1 — Adversarial Search & Game Theory (Lab 8)

Core Idea: In two-player, zero-sum, perfect-information games, choose actions that maximize your outcome assuming an optimal adversary. Build a game tree, evaluate leaves, back up values with Minimax, and prune with Alpha–Beta.

🎮 Game Model Essentials

ComponentDescription
Initial Statestarting position
Player(s)MAX or MIN to move
Actionslegal moves generator
Transition Modelnext state from (s, a)
Terminal-TestisEnd(s) → True/False
Utility(s)payoff at terminal (e.g., +1/0/−1)

📈 Visual: Game Tree Flow

Decision Levels

  • L0: MAX chooses best child
  • L1: MIN chooses worst for MAX
  • Repeat until leaves

Value Backup

  • Leaf eval → heuristic/utility
  • MIN node: min(children)
  • MAX node: max(children)

💡 Must-Know Functions (Conceptual)

FunctionDescription
actions(s)list of legal moves
result(s, a)next state
terminal_test(s)boolean terminal check
utility(s) or heuristic(s)score

📜 Minimax: Template

def minimax(s, depth, maximizing):
    if depth == 0 or terminal_test(s):
        return heuristic(s)
    if maximizing:
        v = -float("inf")
        for a in actions(s):
            v = max(v, minimax(result(s, a), depth-1, False))
        return v
    else:
        v = float("inf")
        for a in actions(s):
            v = min(v, minimax(result(s, a), depth-1, True))
        return v

✂ Alpha–Beta Pruning: Template

def alphabeta(s, depth, alpha, beta, maximizing):
    if depth == 0 or terminal_test(s):
        return heuristic(s)
    if maximizing:
        v = -float("inf")
        for a in actions(s):
            v = max(v, alphabeta(result(s, a), depth-1, alpha, beta, False))
            alpha = max(alpha, v)
            if beta <= alpha:
                break  # prune
        return v
    else:
        v = float("inf")
        for a in actions(s):
            v = min(v, alphabeta(result(s, a), depth-1, alpha, beta, True))
            beta = min(beta, v)
            if beta <= alpha:
                break  # prune
        return v

Exam Tip: Alpha–Beta never changes the returned minimax value. It only reduces explored nodes. Best-case complexity with optimal move ordering approaches O(b^(m/2)).

🏆 Three Classical Problems (with Outlines)

  1. Tic-Tac-Toe Optimal Play
    State: 3×3 grid; Actions: place mark; Terminal: win/lose/draw; Utility: +1/−1/0.
    Heuristic (non-terminal): counts of open lines. Use alphabeta depth-limited = remaining cells. Move ordering: center → corners → edges.
  2. Connect-Four Depth-Limited Search
    State: 7×6 board; Actions: drop in non-full column; Heuristic: weighted patterns (open 2/3/4).
    Techniques: transposition table, iterative deepening, alpha–beta with column ordering (center-first).
  3. Chess Mini-Engine (Fragment)
    State: FEN; Heuristic: material + piece-square tables.
    Enhancements: quiescence search to avoid horizon effect; move ordering via captures/killer moves; time control via iterative deepening + aspiration windows.

🧩 Module 2 — Constraint Satisfaction Problems with OR-Tools

Core Idea: Assign values to variables from finite domains so all constraints hold. Solve via CP-SAT search with propagation.

⚙ CSP Ingredients

ComponentDescription
VariablesX = {x1,…,xn}
DomainsD(xi) finite sets or ranges
ConstraintsC over subsets of X (e.g., AllDifferent, arithmetic, reified)

🔑 OR-Tools CP-SAT: Must-Know API

API CallDescription
cp_model.CpModel(), cp_model.CpSolver() Initialize model and solver
NewIntVar(lb, ub, name), NewBoolVar(name) Create integer and boolean variables
model.Add(x != y), model.AddAllDifferent(vars) Add various types of constraints
OnlyEnforceIf(b) Reification (conditional constraints)
solver.Solve(model), solver.Value(x), solver.StatusName(status) Solve the model and retrieve results

📜 General CP-SAT Template

from ortools.sat.python import cp_model

m = cp_model.CpModel()
# 1) Variables
x = [m.NewIntVar(1, 9, f"x{i}") for i in range(9)]
# 2) Constraints
m.AddAllDifferent(x)
# 3) Optional objective
# m.Maximize(x[0] + x[1])
# 4) Solve
s = cp_model.CpSolver()
status = s.Solve(m)
print(cp_model.OPTIMAL == status, [s.Value(v) for v in x])

🏆 Three Classical CSP Problems

  1. Map Coloring (Four-Color style)
    Vars: region colors 1..4.
    Constraints: adjacent regions ≠.
    Tricks: use model.Add(x[i] != x[j]) per edge; symmetry-break by fixing first region’s color; optional objective: minimize color index spread.
  2. N-Queens
    Vars: q[i] column of queen in row i, domain 0..N−1.
    Constraints: AllDifferent(q), AllDifferent(q[i]+i), AllDifferent(q[i]−i).
    Scale: N up to a few thousands with CP-SAT; add search hints via m.AddHint.
  3. Sudoku (9×9)
    Vars: cell[r][c] in 1..9.
    Constraints: row/col/subgrid AllDifferent; fix clues; optional decision strategy: m.AddDecisionStrategy(flat_vars, cp_model.CHOOSE_FIRST, cp_model.SELECT_MIN_VALUE) for speed.

📜 Pipeline Template

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.pipeline import Pipeline
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

num_pipe = Pipeline([("scaler", StandardScaler())])
cat_pipe = Pipeline([("oh", OneHotEncoder(handle_unknown="ignore"))])

pre = ColumnTransformer([
    ("num", num_pipe, num_cols),
    ("cat", cat_pipe, cat_cols),
])

clf = Pipeline([
    ("pre", pre),
    ("est", LogisticRegression(max_iter=1000)),
])

X_train, X_test, y_train, y_test = train_test_split(
    X, y, stratify=y, random_state=42
)
clf.fit(X_train, y_train)
print(clf.score(X_test, y_test))

🤖 Module 4 — Supervised Learning (Lab 10)

Core Idea: Learn mapping x → y from labeled data for regression (continuous y) and classification (categorical y).

📏 Linear Regression

Model: y = β0 + β1 x (+ higher dims). Training: minimize MSE. Metrics: MSE, RMSE, R². 

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

lr = LinearRegression().fit(X_train, y_train)
pred = lr.predict(X_test)
print("RMSE", mean_squared_error(y_test, pred, squared=False),
      "R2", r2_score(y_test, pred))

from sklearn.tree import DecisionTreeClassifier

Best Practices: tune max_depth, min_samples_split, min_samples_leaf; prefer ensembles (RandomForest, GradientBoosting) for accuracy; keep trees shallow for interpretability.

🏆 Three Classical Supervised Problems

  1. Iris Classification with SVM
    Binary target (e.g., setosa vs others) → SVC(kernel="rbf", C=1, gamma="scale"), standardize features, evaluate with accuracy and confusion matrix.
  2. House Prices Regression
    Numerical + categorical features → ColumnTransformer (scale numeric, one-hot categorical), model via LinearRegression or RandomForestRegressor, metric RMSE.
  3. Spam Detection (Logistic Regression)
    TF-IDF vectorization → LogisticRegression(max_iter=1000), metrics: accuracy, precision, recall, F1; handle class imbalance with class_weight="balanced".

🧬 Module 5 — Unsupervised Learning (Lab 11)

Core Idea: Discover structure without labels—clustering, association, dimensionality reduction.

💎 K-Means Clustering

Goal: partition into K clusters minimizing within-cluster SSE. Init: k-means++. Scale: standardize features. 

from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

sc = StandardScaler()
Xs = sc.fit_transform(X)
km = KMeans(n_clusters=K, init="k-means++", random_state=42)
labels = km.fit_predict(Xs)

📉 Choosing K (Elbow & Silhouette)

import numpy as np
from sklearn.metrics import silhouette_score

wcss, sil = [], []
for k in range(2, 11):
    km = KMeans(n_clusters=k, init="k-means++", random_state=42).fit(Xs)
    wcss.append(km.inertia_)
    sil.append(silhouette_score(Xs, km.labels_))

🏆 Three Classical Unsupervised Problems

  1. Customer Segmentation
    Use (income, spend_score, recency, frequency, monetary). Standardize, run k-means, profile clusters via means; validate with silhouette.
  2. Image Compression with K-Means
    Reshape pixels to (N, 3), fit K clusters in RGB space, replace each pixel by its centroid color, reshape back to image.
  3. Document Clustering
    TF-IDF features → k-means or MiniBatchKMeans; evaluate qualitatively via top terms per cluster and silhouette where feasible.

❓ FAQs

When do I use StandardScaler vs MinMaxScaler?
StandardScaler for algorithms assuming standardized features (SVM, LR, k-means distance-based); MinMaxScaler for bounded features or when preserving zero sparsity and scale-sensitive models.

Does Alpha–Beta change the optimal move?
No. It prunes unreachable branches but preserves the exact minimax decision.

How to avoid data leakage in sklearn?
Use Pipelines / ColumnTransformer; fit scalers/encoders on training data only; perform cross-validation on the full pipeline.
